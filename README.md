# 職人百寶箱

機電自檢・清查資料・沒網路也能用。**不用帳號、不用安裝。**

現場同仁用手機清點數量、拍照，當場看得到還差多少；
回工務所把備份匯進後台，彙整成分區分樓層的清點統計。

## 使用

1. 手機開網址 → 點案場卡片 → 輸入**案場密碼**與**清點人員姓名**（姓名填一次就記住）
2. 選**棟別／樓層／系統**，用搜尋框找到項目，填今天清點到的數量
   每列會顯示該項的**標單數量**與**本機已清點累計**；填超過標單時輸入框變紅
3. 「＋ 照片」拍現場照（自動壓到 1600px），可填備註
4. 「儲存」寫入本機；「🖨 預覽／列印」出 A4 清點統計表

第一次使用前，這台裝置必須先由管理者匯入**案場設定檔**，否則沒有標單基準可比對。

**加到主畫面**：iPhone Safari 分享鍵 → 加入主畫面；Android Chrome ⋮ → 加到主畫面。

## 案場設定檔

標單基準與兩組密碼都放在這個檔案裡，**不在這個公開的網站程式中**。

| 內容 | 說明 |
|---|---|
| 項目 | 棟別／樓層／系統／項次／項目及說明／單位／該層標單數量 |
| 案場密碼雜湊 | 同仁進入案場時驗證 |
| 管理者密碼雜湊 | 開啟後台時驗證 |

兩組密碼都是加鹽後的 SHA-256，檔內沒有明碼。產生方式見 [`tools/`](tools/)。

管理者在後台「📦 匯入案場設定檔」載入，之後用「📤 匯出案場設定檔」重新產生一份轉發給同仁。

## 後台（需管理者密碼）

分頁預設隱藏，首頁底部「🔒 管理者登入」輸入密碼後才出現。

同仁按「💾 備份」匯出 zip（LINE／Email 傳回），後台「📥 匯入同仁備份」可一次匯入多個檔案，自動去重。

| 匯出 | 內容 |
|---|---|
| 清點統計表 | Excel，逐項列出標單數量、已清點數量、差異、完成狀態 |
| 清點明細 | Excel，一列一個清點項目，含編號、清點人、備註 |
| 照片打包 | zip，依 `編號_棟別樓層-系統/` 歸檔 |

統計以**棟別×樓層×系統**為單位：標單項數、已清點項數、完成率。

> 「已清點」是**這台裝置**的累計。要看全隊進度，得先把同仁的備份匯進來，或走線上空間。

## 線上空間（選用）

預設**所有資料只存在各自的手機**，沒有任何伺服器。

管理者若要把資料集中起來，可在首頁按「🔒 管理者登入」，接上自己部署的 Google Apps Script：
紀錄寫進你的 Google 試算表，照片存進你的雲端硬碟，同一筆重傳會覆蓋不會重複。
設定方式見 [`cloud/安裝說明.md`](cloud/安裝說明.md)。

通行碼由 Apps Script 伺服器端驗證，**不寫在這個網站的程式碼裡**——網站是 public，
任何寫在前端的密碼都讀得到。網址與通行碼只留在管理者那台裝置的瀏覽器。

## 版面

頂部橫幅與整頁底圖用的是工地實景照片（`hero.jpg` / `bg.jpg`）。要換照片就換掉這兩個檔，
並把 `sw.js` 的 `CACHE` 版號往上加一號，手機下次開啟才會抓到新的。
橫幅只出現在清單頁與後台頁，填表時會收起來把捲動空間留給逐項檢查。
A4 列印與匯出的 Word 不放任何底圖。

## 部署（GitHub Pages）

```bash
git remote add origin https://github.com/<帳號>/mep-check.git
git branch -M main
git push -u origin main
```

GitHub repo → Settings → Pages → Source 選 **Deploy from a branch**、分支 `main` `/ (root)` → Save。
約一分鐘後網址是 `https://<帳號>.github.io/mep-check/`。

## 注意

- **資料只存在各自的手機**，換手機或清除瀏覽器資料前務必先「備份」
- 照片會自動壓到 1600px 再存，省空間也省流量
- 離線能力靠 Service Worker，**必須是 https（GitHub Pages 本來就是）**，第一次開啟需有網路把程式快取下來
