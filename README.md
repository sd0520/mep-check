# 職人百寶箱

機電自檢・清查資料・沒網路也能用。**不用帳號、不用安裝。**

- 現場用手機填表、拍照，資料存在自己手機裡
- 回工務所按「備份」把檔案傳回，後台匯入後彙整成管理文件

## 使用

1. 手機開網址 → 右上「✎ 工地」填工程名稱（只填一次）
2. 「＋ 新增查驗」→ 選分項工程 → 逐項按 **○ 合格 / ╳ 缺失 / ／ 無此項** → 填實際檢查情形 → 拍照
3. 「🖨 預覽／列印」可直接出 A4 檢查表（含簽名欄與照片頁），手機也能存成 PDF
4. 「儲存」寫入本機

**加到主畫面**：iPhone Safari 分享鍵 → 加入主畫面；Android Chrome ⋮ → 加到主畫面。

## 後台（工務所用電腦開）

同仁按「💾 備份」匯出 zip（LINE／Email 傳回），在「後台」頁「📥 匯入同仁備份」可一次匯入多個檔案，自動去重。之後可產出：

| 匯出 | 內容 |
|---|---|
| 清查總表 | Excel，一列一次查驗，含合格／缺失／無此項計數與改善狀態 |
| 缺失追蹤表 | Excel，只列 ╳ 的項次，附管理項目、抽查標準、實際情形 |
| 照片打包 | zip，依 `編號_區域樓層-工項/自檢照片/01_管理項目.jpg` 歸檔 |
| 自主檢查表 Word | .docx，表頭＋逐項表格＋照片頁，一次最多 20 份 |

## 線上空間（選用）

預設**所有資料只存在各自的手機**，沒有任何伺服器。

管理者若要把資料集中起來，可在首頁按「🔒 管理者登入」，接上自己部署的 Google Apps Script：
紀錄寫進你的 Google 試算表，照片存進你的雲端硬碟，同一筆重傳會覆蓋不會重複。
設定方式見 [`cloud/安裝說明.md`](cloud/安裝說明.md)。

通行碼由 Apps Script 伺服器端驗證，**不寫在這個網站的程式碼裡**——網站是 public，
任何寫在前端的密碼都讀得到。網址與通行碼只留在管理者那台裝置的瀏覽器。

## 版面

頂部橫幅與整頁底圖用的是工地實景照片（`hero.jpg` / `bg.jpg`）。要換照片就換掉這兩個檔，
並把 `sw.js` 的 `CACHE` 版號往上加一號，手機下次開啟才會抓到新的。
橫幅只出現在清單頁與後台頁，填表時會收起來把捲動空間留給逐項檢查。
A4 列印與匯出的 Word 不放任何底圖。

## 檢查表範本

5 個工項，管理項目與抽查標準取自本案 `13.施工查驗` 既有、監造已認可的自主檢查表：

電氣配管工程、弱電配管工程、給排水配管工程、避雷及接地設備工程（SUS304雙連出線盒）、接地工程。

現場可按項目旁的「修改標準」臨時調整；要永久增修工項，改 `app.js` 最上方的 `TEMPLATES`。

## 部署（GitHub Pages）

```bash
git remote add origin https://github.com/<帳號>/mep-check.git
git branch -M main
git push -u origin main
```

GitHub repo → Settings → Pages → Source 選 **Deploy from a branch**、分支 `main` `/ (root)` → Save。
約一分鐘後網址是 `https://<帳號>.github.io/mep-check/`。

## 注意

- **資料只存在各自的手機**，換手機或清除瀏覽器資料前務必先「備份」
- 照片會自動壓到 1600px 再存，省空間也省流量
- 離線能力靠 Service Worker，**必須是 https（GitHub Pages 本來就是）**，第一次開啟需有網路把程式快取下來
