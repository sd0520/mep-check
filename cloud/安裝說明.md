# 線上空間 — 安裝說明

App 本身不需要任何伺服器，資料存在各自手機裡。
**只有管理者要把資料集中起來時**，才需要這一套。裝好之後，資料寫進**你自己的** Google 試算表與雲端硬碟。

現場同仁完全不受影響，也不需要知道這個網址。

---

## 一、建立專案（約 5 分鐘，只做一次）

1. 開 <https://script.google.com> → **新增專案**
2. 左側 `程式碼.gs` 全選刪除 → 貼上本資料夾 **`Code.gs`** 的全部內容
3. 把最上方這行改成你要的通行碼：
   ```js
   var PASSCODE = '請改成你的通行碼';
   ```
   這組通行碼等一下要輸入進 App，**不會出現在網站的程式碼裡**。
4. 存檔（Ctrl+S），專案名稱改成「職人百寶箱線上空間」

## 二、初始化

1. 上方函式下拉選 **`setup`** → 按 **執行**
2. 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往…（不安全）」→ 允許
   （這是 Google 對未發布程式的標準提示，因為程式要寫你的試算表與雲端硬碟）
3. 執行紀錄會印出建立好的兩樣東西，在「我的雲端硬碟」根目錄：
   - 試算表 **職人百寶箱_查驗紀錄**（分頁：查驗紀錄、檢查項目）
   - 資料夾 **職人百寶箱_自檢照片**

   可以搬進專案資料夾，搬動不影響運作。

> 之後若要換通行碼：改最上方那行，再執行一次 `setup()` 即可，不必重新部署。

## 三、部署成網址 ★關鍵步驟

右上 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**：

| 欄位 | 要選什麼 | 為什麼 |
|---|---|---|
| 說明 | 線上空間 v1 | 隨意 |
| **執行身分** | **我（你的帳號）** | 程式用你的權限寫檔案 |
| **誰可以存取** | **所有人** | App 是從瀏覽器直接呼叫，沒登入身分可帶 |

按 **部署** → 複製「網頁應用程式」網址，長這樣：

```
https://script.google.com/macros/s/AKfycb.../exec
```

> 「所有人」指的是**任何人都能把請求送到這個網址**，不是任何人都能存資料——
> 程式第一件事就是比對通行碼，不對就直接退回。所以**通行碼才是真正的鎖**，別外流。

## 四、在 App 裡登入

1. 開 <https://sd0520.github.io/mep-check/>
2. 首頁最下方 **🔒 管理者登入**
3. 貼上 `/exec` 網址 ＋ 輸入通行碼 → **測試並登入**
4. 成功後切到「後台」，會多出一張 **☁ 線上空間** 卡片
5. 按 **⬆ 存入線上空間**，紀錄與照片一起上傳

網址與通行碼只存在**你這台裝置**的瀏覽器裡，不會同步給任何人。按「登出」即清除，本機資料不受影響。

---

## 上傳了什麼

| 位置 | 內容 |
|---|---|
| 試算表「查驗紀錄」 | 一列一次查驗，含合格／缺失／無此項計數、改善狀態、照片數、照片資料夾連結 |
| 試算表「檢查項目」 | 逐項明細。篩「抽查結果 = ╳」就是缺失追蹤表 |
| 雲端硬碟 | `編號_區域樓層-分項工程/自檢照片/01_管理項目.jpg` |

**同一筆重傳會覆蓋**，不會變成兩筆——程式用「編號」比對，舊的照片資料夾會先清掉再寫入。
所以缺失改善後重新上傳，線上資料會跟著更新。

## 修正後要記得重傳

在後台按「標記已改善」之後，那一筆的上傳狀態會退回未上傳，
卡片上的「已上傳 N/M」會變少，再按一次「存入線上空間」就會把最新狀態推上去。

## 遇到問題

| 訊息 | 原因 |
|---|---|
| 通行碼不正確 | 通行碼打錯，或改了 `PASSCODE` 卻沒重跑 `setup()` |
| 伺服器尚未執行 setup() | 跳過了第二步 |
| 網址格式不對 | 要用 `/exec` 結尾那個，不是 `/dev` |
| 伺服器回應不是預期格式 | 部署時「誰可以存取」沒選「所有人」，Google 回了登入頁 |

照片很多時單筆會跑比較久（程式給到 120 秒）。若某筆失敗，卡片會顯示失敗筆數與原因，
修正後再按一次「存入線上空間」即可——已成功的不會重傳。
